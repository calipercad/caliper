An 18-tooth involute gear, hidden-line rendered — in your terminal.

What it is

One small Rust kernel — no cargo dependencies — that does genuinely hard CAD: exact-integer 2D booleans, holed extrusion, 3D mesh CSG, a 2D geometric constraint solver, and an AI copilot that speaks the same command language you do. Think OpenSCAD meets a constraint sketcher, in the terminal.

Capabilities

Exact 2D geometry

Integer-exact booleans, fillets/chamfers, polygon offset & inset — real holes that survive extrusion.

3D solids & CSG

BSP mesh union/difference/intersection, shell, and edge fillet/chamfer — manifold-verified output.

Constraint solver

Sketch points, segments, arcs & circles; constrain (perpendicular, tangent, radius…) and solve.

AI copilot

Describe it in English; the model emits the same commands you type, inspecting & repairing as it goes.

20+ parametric skills

Gears, enclosures, gridfinity, sprockets, living hinges, monograms — driven by real engineering math.

Measurement

Area, volume, centroid, surface area, genus, interference/clash, and planar cross-sections.

Text as geometry

Single-stroke engraving text, and filled TrueType outlines for through-cuts and stencils.

Everything exports

SVG, DXF, G-code (G2/G3 arcs), STL (ASCII+binary), OBJ — real-world units, layered by role.

Live terminal UI

cad tui: orbit the model with the arrow keys and watch it re-render as you type.

60-second start

# install
cargo install --path crates/cad-cli

# build a bored block, measure it, export for printing
box 40 40 20 name=blk
cylinder 8 30 name=bore
translate 20 20 -5 target=bore
subtract blk bore name=part
measure part            # volume · surface · genus
export stl part.stl name=part

# or just ask
ai a phone stand with a cable slot
