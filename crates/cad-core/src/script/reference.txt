cad-assist script language
===========================
One command per line. `#` or `;` begins a comment. Text in "double quotes"
is one token. Options are key=value; bare numbers are positional. Angles are
degrees; lengths are in the current document units (default mm). Most creators
accept name=<id>; if omitted, a name is auto-generated and auto-selected.

2D PRIMITIVES (lie in the XY plane)
  rect <w> <h> [rx=<corner>] [seg=8] [name=]      rectangle (rx rounds corners)
  circle <r> [seg=64] [name=]                      circle
  polygon <sides> <r> [name=]                      regular polygon
  star <points> <r_outer> <r_inner> [name=]        star
  arc <r> <start_deg> <end_deg> [seg=48] [name=]   open circular arc
  path <x1> <y1> <x2> <y2> ... [closed] [name=]    polyline (add `closed`)
  text "<string>" [h=10] [align=left|center|right] [name=]
                                                   single-stroke engraving/plot text
  (any 2D primitive also accepts [layer=<name>] [role=cut|score|engrave])

3D PRIMITIVES (solids; base sits on the XY plane)
  box <w> <d> <h> [name=]                          rectangular box
  cylinder <r> <h> [seg=48] [name=]                cylinder
  sphere <r> [seg=32] [name=]                       sphere
  cone <r> <h> [seg=48] [name=]                    cone

OPERATIONS (default target = current selection; override with target=<id>)
  extrude <height> [target=] [name=]               2D shape -> 3D solid
  revolve [seg=48] [target=] [name=]               revolve a profile about Z
  translate <x> <y> [z] [target=]                  move
  rotate <deg> [axis=x|y|z] [about=center|origin] [target=]
  scale <factor> [about=center|origin] [target=]
  union <a> <b> [name=]                            a ∪ b  (2 shapes OR 2 meshes -> new)
  subtract <a> <b> [name=]                         a − b  (2D or 3D, by operand kind)
  intersect <a> <b> [name=]                        a ∩ b  (2D or 3D)
  xor <a> <b> [name=]                              a ⊕ b  (2D shapes only)
  fillet <r> [seg=16] [target=]                    round contour corners (2D)
  chamfer <d> [target=]                            bevel contour corners (2D)
  shell <t> [target=]                              hollow a solid to wall t (convex/prism)
  array <n> [kind=linear|polar|grid] [dx= dy= dz=] [nx= ny=] [about=] [target=] [name=]
                                                   replicate (polar spins about Z; name= groups)
  mirror [axis=x|y|z] [about=center|origin] [copy] [target=]   reflect (copy keeps original)
  group <a> <b> … name=<tag>                       tag entities into a group
  ungroup <tag>                                    clear a group tag
  dim <target> [name=]                             bbox dimension annotation (role=dim)
  layer <name> [target=]                           set an entity's export layer
  role <name> [target=]                            set cut|score|engrave (layer color)
  (transforms/array/mirror act on a whole group when target= names a group)
  (rounded/beveled 3D edges: fillet/chamfer the 2D profile, then extrude)

SKILLS (parametric generators — run `skills` for the full list + usage)
  skill gear teeth=<n> module=<mm> [pressure=20] [bore=<mm>] [thickness=<mm>]
  skill boxjoint width= depth= height= thickness= [finger=] [lid] [gap=10]
  skill honeycomb width= height= [cell=10] [wall=2] [margin=5]
  skill washer outer=<r> inner=<r> [thickness=<mm>]
  skill standoff outer=<r> bore=<r> height=<mm>
  — mechanical —
  skill flange [outer=60] [bore=20] [bolt_circle=45] [bolt_dia=5] [bolts=4] [thickness=0]
  skill sprocket [teeth=17] [pitch=12.7] [roller=7.95] [bore=10] [thickness=0]
  skill rack [teeth=10] [module=2] [pressure=20] [height=10] [thickness=0]
  skill pulley [teeth=20] [belt=GT2|HTD3M|HTD5M] [bore=5] [thickness=0]
  skill cam [base=20] [lift=10] [motion=harmonic|cycloidal] [rise_deg=120] [dwell_deg=60] [bore=6]
  — maker / 3D —
  skill gridfinity [units_x=2] [units_y=1] [height_u=3]
  skill enclosure [width=80] [depth=60] [height=30] [wall=2] [lid] [standoffs]
  skill standoff_grid [nx=3] [ny=2] [pitch=20] [outer=6] [bore=3] [height=10] [base]
  skill knob [diameter=30] [height=15] [flutes=12] [bore=6] [d_flat=0]
  skill cable_clip [cable=6] [thickness=3] [depth=8] [screw=3]
  — craft / laser —
  skill monogram [text=AB] [size=30] [frame=circle|rect|none]
  skill mandala [petals=12] [rings=2] [r=40]
  skill card [width=100] [height=70] [fold=left|top] [window=0]
  skill box_template [width=60] [depth=40] [height=30] [tab=10]
  skill living_hinge [width=80] [height=40] [slot=15] [gap=3] [rows=0]
  skill <name> ...                                 also runs ~/.cad-assist/skills/<name>.cad

SCENE / INSPECTION
  units mm|cm|in         list          bbox [name]
  select <name>          delete <name>  clear         skills        help

RENDER (ASCII/braille preview)
  render [name] [w=cols] [h=rows] [yaw=deg] [pitch=deg]
         [mode=wire|hlr|shade]   wire edges / hidden-line removal / shaded (ANSI)
         [view=iso|top|front|right]   camera preset
         [layout=views]          tile top/front/right/iso into a 2×2 sheet
         [axes=on|off]           scale-bar overlay (3D single view)

EXPORT
  export svg   <path> [name=]     Cricut / Silhouette / laser / vinyl (mm)
  export dxf   <path> [name=]     AutoCAD / LibreCAD / Fusion
  export gcode <path> [name=]     pen plotter / drag knife / CNC contour
  export stl   <path> [name=]     3D printing / slicers
  export obj   <path> [name=]     3D mesh interchange
  (omit name= to export every matching entity — good for laser layouts)
  SVG/DXF group entities onto layers (by layer=, else role=) and color each
  layer by role: cut=black, score=blue, engrave=red.

FILES & AI
  save <file.cad>        write the command history as a reproducible script
  load <file.cad>        run a script file
  ai <describe it>       ask Claude to generate and run a design

EXAMPLE
  units mm
  skill gear teeth=24 module=2 bore=5 thickness=6 name=g1
  render
  export stl gear.stl name=g1
